# Handwritten-digit-recognition

Build a handwritten number recognition system, users write numbers on the screen, through the back-end trained deep learning model for automatic recognition, the accuracy rate is not less than 90%, the system supports both PC and mobile applications (it is recommended to carry out handwritten number recognition on the mobile phone, and the management function on the PC side), consider the implementation of WeChat interface (WeChat mini program) or independent APP application, in addition to system management functions, such as managing models, model training, managing users, and statistical functions. Enhancements: Support for continuous handwritten number recognition. Core functions: model training management function, model management function.Model training management: It supports the visualization of the whole process of deep learning model training, and can provide users with intuitive visibility from the selection of datasets, parameter settings, process data display, model saving, etc., so that users who simply understand deep learning can train models and put them into use through this function.Model management: The system can train multiple models, and only one model is active at the same time, and the administrator can adjust the model according to the feedback of the model, and can easily and conveniently switch the trained model to the effective state.It is recommended that the system is implemented based on JAVA design, and the model side is based on PYTHON language.Difficulties: Heterogeneous system (Java Python) integration scheme, model visualization;
Datasets: MINIST and extended datasetsModel: Existing CNN models can be usedFramework: It is recommended to use the Springboot+vue framework and the flask framework

构建手写数字识别系统，用户在屏幕上写数字，通过后端训练好的深度学习模型进行自动识别，准确率不低于90%，系统既支持PC端也支持手机端的应用（建议手机端进行手写数字识别，PC端进行管理性的功能），考虑与微信接口（微信小程序）实现或独立APP应用，此外有系统管理功能，如管理模型，模型训练，管理用户，统计功能。增强功能：支持连续的手写数字识别。核心功能：模型训练管理功能，模型管理功能。模型训练管理：支持深度学习模型训练的全过程可视化，从数据集的选择、参数设置、过程数据展示、模型保存等环节均能对用户做到直观可视，让简单了解深度学习的用户能通过该功能训练模型并投入使用。模型管理：系统可以训练多个模型，同时只有一个模型是活跃的，管理员可以根据模型使用反馈进行模型的调整，能简单方便的切换已经训练好的模型为生效状态。建议系统基于JAVA设计实现，模型端基于PYTHON语言设计实现。难点：异构系统（Java Python）集成方案，模型可视化；数据集：MINIST 及扩展数据集模型：可以采用现有CNN模型框架：建议采用Springboot+vue框架，flask框架
